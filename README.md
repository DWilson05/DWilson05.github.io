Track Team Roster Website

A responsive and interactive website to showcase track team members. Built with HTML, CSS, and JavaScript.

Features

Search bar at the top to quickly find athletes by name (with auto-scroll to their profile).

Team roster cards with athlete photos, events, strengths, and descriptions.

Hover effects: profile pictures expand and reveal more detail with text resizing.

Image popup modal: click on any athlete photo to enlarge it.

Roster separation: distinct sections for men’s and women’s teams with styled banners.

About Me / Resume section at the bottom with a project description and photo.

Custom styling: dark background with gold highlights and team colors.
